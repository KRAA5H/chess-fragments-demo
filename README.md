# Chess Fragments demo

Companion page for my COMP2321 AI coursework presentation (Krish Mathur).

The coursework is a small-board chess variant. An agent is a single Python file with
`agent(board, player, var)` that returns a piece and a move. Games are refereed by the
course package with a 14 second move clock and a 300 second game clock.

## What is here

This repository is a clean demo page. It has no coursework code and no history from my
working repository. A runnable copy of my agent and instructions for playing your own
agent against it are not added yet.
